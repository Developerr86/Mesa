# Mesa food detector

An on-device object detector that finds **every** dish on a plate (roti, dal, rice, sabzi…), not just one. It runs in the app as part of recognition pass 2, alongside the food_V1 classifier (see `src/features/recognition/recognizeFood.ts`).

- Model: Ultralytics **YOLO11n**, trained at 416×416, exported to TFLite → `assets/models/food_detector.tflite`
- Classes: 42, defined in `prepare_dataset.py` (`CLASSES`), each mapped to a dish id in our food database (or none, e.g. generic "curry")
- App label map: `src/features/recognition/detectorClasses.json` (generated by `prepare_dataset.py`)

## Retraining

1. Download each dataset from Roboflow Universe as **COCO JSON** (free account) and unzip each into one folder, e.g. `exports/Indian_Food.v2i/`.
2. Build the merged YOLO dataset:
   ```bash
   python3 data/food-detector/prepare_dataset.py exports/ yolo-data/
   ```
3. Train and export (Python 3.12 with `pip install ultralytics`):
   ```bash
   yolo detect train model=yolo11n.pt data=yolo-data/dataset.yaml epochs=40 patience=10 imgsz=416 batch=32 device=mps
   yolo export model=runs/detect/train/weights/best.pt format=tflite imgsz=416
   ```
4. Copy the exported `best_float32.tflite` to `assets/models/food_detector.tflite`.

To add a dataset, add its category mapping to `SOURCE_CLASSES` (and any new classes to `CLASSES`).
